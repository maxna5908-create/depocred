# Автоматическая отправка в App Review

В main: Actions → **iOS App Store**.

- `release=false`, `submit_review=false`: проверки iPhone/iPad, без загрузки в Apple.
- `release=true`, `submit_review=false`: подписанный IPA в App Store Connect/TestFlight.
- `submit_review=true`: сборка, подпись, загрузка, ожидание обработки Apple, обновление текстов карточки, выбор именно загруженного build и отправка на App Review. После одобрения — автоматический выпуск.

Для общего выпуска Android и iOS: **Release all stores**, флаг `publish`. По умолчанию выключен.

Тексты карточки: `ios/fastlane/metadata/ru`. Перед функциональным релизом обновите release_notes.txt и description.txt. Текущие маркетинговые скриншоты в Apple сохраняются, вместо них не загружаются необработанные тестовые снимки. При изменении экранов подготовьте обновлённые креативы; скрипт submit_review.py поддерживает явный --screenshots с fastlane-структурой каталогов.

Существующие юридические данные, контакты App Review, возрастной рейтинг, территории и соглашения аккаунта остаются в App Store Connect. Если Apple требует их дополнить, отправка завершится ошибкой, не выдумывая данные владельца. Секреты API используются только в runner; временный ключ удаляется.

Настройка проверяется локальными тестами и CI без отправки. Реальная приёмка автоматической отправки возможна при следующем разрешённом выпуске. Текущий проход не загружает и не публикует новую версию Apple.
