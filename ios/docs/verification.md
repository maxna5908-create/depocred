# Проверка перед выпуском

## Автоматически

- 30 кредитных и 140 депозитных эталонов; каждый месяц графика.
- Восстановление ставки кредита для обоих типов платежей, включая 0%, длинные сроки и высокие ставки.
- Все неизвестные обратного депозита, периоды пополнения/капитализации, последовательности ввода и очистка полей.
- Примеры лизинга заказчика, НДС, комиссии, выкуп, отсрочка, группы и нулевые платежи, отрицательная ставка предложения.
- Дисконтированные потоки и сумма погашения сходятся с полученным финансированием.
- История всех трёх инструментов сериализуется без потерь; повреждённый JSON сохраняется и восстанавливается из последней корректной копии.
- Повторный запуск открывает пустой Депозит, настройки сохраняются.
- PDF содержит кириллицу и все месяцы, включая 999-месячный многостраничный график.
- UI: обязательное поле, Next/Done, расчёт/сохранение/повторный запуск, кредитные закладки, лизинг, темы, возврат Инфо наверх.

## На устройстве через TestFlight

- Холодный запуск: оранжевая системная заставка, белый логотип, 0,9 с анимации + 1,5 с удержания + 0,6 с перехода. Фон покрывает safe area.
- Иконка: белые монеты на оранжевом фоне, без зелёного. Проверить обычный и крупный размер иконок iOS.
- Светлая/тёмная темы и все 5 скинов; поля прозрачные, отключённые слегка обозначены.
- iPhone: небольшая ширина, landscape, увеличенный системный текст. iPad: portrait/landscape, изменение размеров окна.
- VoiceOver: названия полей, выбранные пункты меню, кнопки сохранения/отправки/очистки. Reduce Motion: нет принудительного масштабирования.
- «Далее» переносит курсор без закрытия клавиатуры; конечное поле — «Применить». Пустой расчёт показывает сообщение и нужное поле.
- Переключение главных разделов возвращает страницу наверх сразу. Переключение результатов аннуитет/дифференцированный не сбрасывает позицию на исходную форму.
- Сворачивание сохраняет черновик; завершение приложения очищает его. История/тема сохраняются после обновления.
- Прямой и обратный расчёт каждого инструмента, нулевая ставка, десятичные суммы, очистка автоматически вычисленного поля депозита.
- Сохранить 10 расчётов разных типов, отфильтровать, открыть график, удалить один. 11-й новый расчёт вытесняет самый старый.
- Сохранить PDF в локальные «Файлы» и iCloud Drive по выбору пользователя; отмена окна не должна давать ошибку. Отправить PDF через доступное приложение. Проверить все строки и кириллицу.
- Удаление приложения удаляет его историю, но не экспортированные пользователем PDF.

Результаты фактических запусков хранятся в GitHub Actions. Этот чек-лист описывает требуемые проверки и сам по себе не утверждает, что они уже пройдены на физическом устройстве.
