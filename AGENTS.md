* **Счетчик сборки:** При каждом новом запросе к ассистенту обязательно увеличивайте значение `BUILD_VERSION` на 1 в файле `src/lib/version.ts`.

Исходники и конфигурация сборки находятся в `main`. Изменения вносятся через PR. Веб-клиент проверяется командами `npm ci`, `npm run lint` и `npm run build`. Подписание и публикация выполняются отдельными workflow.
