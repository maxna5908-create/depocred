# Выпуск DepoCred в RuStore

Пакет `ru.depocred.app`, приложение `2063712429`. Используются существующие секреты `RUSTORE_KEY_ID` и `RUSTORE_PRIVATE_KEY`.

## Рекомендуемый запуск

Actions → **Android stores** → Run workflow. Без отмеченных магазинов создаются подписанные APK/AAB, отчёты и скриншоты, ничего не публикуется. Отметьте `google_play` и/или `rustore` только для выпуска в выбранные магазины. Оба используют одну проверенную Android-сборку. Для всех трёх магазинов есть **Release all stores**: `publish=false` — проверка, `true` — выпуск Android и отправка iOS на App Review.

## Публикация ранее собранной версии

Actions → **Publish Android to RuStore** → укажите `source_run_id` успешного запуска Native Android, Android Google Play, Android stores или Release all stores. Современные сборки передают исходный SHA в `android-source-provenance`; старые прямые Native Android запуски используют head_sha. Подпись, пакет и код версии проверяются до обращения в RuStore. Артефакты доступны 30 дней.

Нет привязки к 1.0.35, ID старого запуска или старому черновику. `resume_version=0` создаёт новый черновик только при отсутствии другого. При незавершённом выпуске укажите его ID явно. Уже отправленная версия не публикуется повторно.

Загружаются описание, изменения версии и 10 креативов: 7 телефонных и 3 планшетных. API использует общий диапазон ordinal 0–9. После проверки сохранённых данных версия отправляется на модерацию с INSTANTLY и охватом 100%.

Обычный push, PR и ветки validation не публикуют в магазины. Ветки validation/android/** собирают подписанные файлы без публикации. Успех отправки означает принятие заявки, а не одобрение модерацией.
