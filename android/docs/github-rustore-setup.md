# Публикация DepoCred в RuStore

Приложение: `ru.depocred.app`, RuStore ID `2063712429`.

Секреты репозитория: `RUSTORE_KEY_ID`, `RUSTORE_PRIVATE_KEY`. Ключ принимает исходный Base64 из RuStore или полный PEM. Значения используются только в GitHub Actions, не попадают в артефакты. Подпись APK использует уже настроенные `DEPOCRED_*` секреты.

## Выпуск

1. В Actions откройте **Native Android** и запустите для `feature/native-android`: `release=true`, `publish=false`. Дождитесь успешного завершения. Это собирает и проверяет APK, AAB и реальные скриншоты телефона и планшетов. Код версии должен быть выше опубликованного.
2. Скопируйте числовой ID запуска из URL `actions/runs/ID`.
3. В Actions откройте **Publish Android to RuStore**, Run workflow: вставьте ID в `source_run_id`. `resume_version` оставьте `0`.
4. Запуск проверит исходную сборку, package name, versionCode и сертификат APK. Загрузит APK, полное и краткое описание с лизингом, изменения версии и 8+8 скриншотов.
5. По умолчанию версия отправляется на модерацию с `publishType=INSTANTLY`, охватом 100%. После одобрения RuStore опубликует её автоматически. Успешный Actions означает принятую заявку, а не завершённую модерацию.

Исходная сборка должна быть прямым успешным запуском `android.yml` в нативной или релизной ветке. Артефакты хранятся 30 дней. Описание берётся из того же коммита, что и APK; скриншоты — из того же запуска. Запуск из PR не принимается.

## Повторный запуск

Создание черновика через API может удалить предыдущий черновик. Поэтому при обнаружении существующего черновика процесс останавливается без его удаления. Проверьте его в консоли и используйте `resume_version` с ID из журнала. Скрипт продолжит загрузку только для той же версии APK; неизвестные APK сохраняет без изменений. Повторный запуск уже отправленной версии не создаёт дубликат.

После ошибки данные остаются в черновике. ID записан в артефакт `rustore-publication/rustore-result.json`. Не удаляйте API-ключ и не меняйте подпись APK для повторного запуска.

## Запуск через release-ветку

Обновите `android/store/rustore-release.json` проверенным ID сборки и отправьте коммит в `release/rustore/<версия>`. Это запускает только публикацию RuStore. Первый выпуск использует проверенные артефакты Android 1.0.35 из запуска `40328972265`; изменение счётчика исходников до 36 готовит следующий выпуск и не меняет уже собранный APK.

Документация API: https://www.rustore.ru/help/work-with-rustore-api/api-upload-publication-app
