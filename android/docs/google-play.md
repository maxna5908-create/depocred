# Подготовка Google Play

Пакет: `ru.depocred.app`. Перед первой публикацией убедиться, что именно этот
идентификатор выбран в Play Console; после публикации его нельзя менять.
Если приложение уже существует в Play Console под другим package name,
использовать его точный `applicationId` до загрузки первого обновления.

## Техническая конфигурация

- Android App Bundle, target API 36, min API 26.
- Release с R8, сокращением ресурсов, без debug и разрешений.
- Ресурсы адаптивной иконки и монохромная иконка для тематического оформления.
- Без браузерного движка/WebView. Нативная библиотека AndroidX Graphics Path
  поддерживает ABI устройств; ELF-сегменты arm64 и x86_64 выровнены на 16 КБ.
- Edge-to-edge, безопасные области, вырезы, системная навигация и клавиатура.
- Интерфейс не заблокирован в портретной ориентации, доступна широкая компоновка.
- PDF создаётся и передаётся офлайн; доступ к файлам не запрашивается.

## Подпись и обновления

Предоставленный сертификат, alias `key0`, SHA-256:

`02:7A:5D:3F:00:40:A1:DC:7A:52:1D:34:79:58:81:FF:66:AE:49:DE:32:79:7A:0A:0D:30:5E:97:39:30:08:C4`

При включении Play App Signing различать **upload key** и **app signing key**.
Если Google подписывает доставляемые приложения другим сертификатом, APK
из локальной сборки с upload key не сможет обновить приложение, установленное
из Play. Для общей линии обновлений использовать согласованную схему подписи.
Хранить приватный ключ и его резервную копию вне репозитория.

- Категория: **Финансы**.
- Почта поддержки в исходнике: `support@depocred.ru`.
- Сайт в исходнике: `https://depocred.ru`.

  Рассчитывайте аннуитетные и дифференцированные платежи, комиссии,

## Действия в Play Console

1. Создать приложение либо открыть существующее с совпадающим package name.
2. Опубликовать политику конфиденциальности по доступному публичному HTTPS URL;
   текст подготовлен в `privacy-policy.md`. Проверить реквизиты владельца и почту.
3. Загрузить подписанный AAB во внутреннее тестирование.
4. Заполнить декларации: реклама отсутствует; доступа к закрытым разделам нет;
   данные приложением не собираются и не передаются разработчику; аккаунтов нет.
   Проверить ответы по действующим формам Console. Отправка выбранного PDF
   осуществляется пользователем в выбранное им стороннее приложение.
5. В разделе финансовых функций указать фактическую функцию калькулятора:
   приложение не выдаёт займы, не принимает вклады, не является банком.
6. Заполнить возрастную анкету, аудиторию, страны и сведения разработчика.
7. Добавить иконку карточки 512×512, feature graphic 1024×500 и реальные
   скриншоты текущей версии, затем проверить Pre-launch report и Android vitals.
8. Проверить отдельные требования к тестированию для типа и возраста аккаунта.

Это подготовка сборки, не подтверждение одобрения Google Play. Публикация,
публичная политика и анкеты Console выполняются владельцем аккаунта.

Официальные источники для проверки перед загрузкой:

- https://developer.android.com/guide/practices/page-sizes
- https://support.google.com/googleplay/android-developer/answer/9859455
- https://support.google.com/googleplay/android-developer/answer/10787469
